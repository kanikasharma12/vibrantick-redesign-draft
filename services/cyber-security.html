Security service capabilities

Security coverage across systems and users.

The official service page identifies assessment, monitoring and protection activities for networks, applications, endpoints, identities, data and cloud environments.

Service overview

The service description combines preventive work, ongoing monitoring and response. Assessments examine networks, applications and systems, while managed security and endpoint capabilities are intended to detect and contain incidents.

Other listed activities address how people access resources, how sensitive data is protected, and how cloud environments are monitored. The official page also describes preparing response plans and investigating the source and impact of security incidents.

Capabilities

Vulnerability assessment and penetration testing

Assess networks, applications and systems for vulnerabilities, and use controlled simulated attacks to evaluate security posture and reveal weaknesses.

Managed security services

Monitor and manage security infrastructure, detect and respond to incidents, and provide the 24/7 Security Operations Center support described on the official page.

Firewall and network security

Design and configure firewalls and network security devices, enforce security policies and help prevent unauthorized access and intrusions.

Endpoint protection

Protect computers, laptops and mobile devices against malware and other threats. Endpoint Detection and Response (EDR) is listed for identifying and containing incidents.

Identity and access management

Plan access to critical resources and implement identity controls such as multi-factor authentication (MFA) and single sign-on (SSO).

Data loss prevention

Monitor for attempts to disclose or transfer sensitive data without authorization and configure controls to help prevent data exfiltration.

Incident response and cyber forensics

Prepare response plans and playbooks, then investigate incidents to understand the source and impact of a breach.

Cloud security

Apply access controls, encryption and monitoring to cloud environments and assess cloud-specific risks.

Security awareness and compliance

Provide employee training on common threats and security practices, and support organizations reviewing industry- and region-specific compliance requirements.
