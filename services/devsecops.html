DevSecOps capabilities

Build, test and release with coordinated workflows.

The official page describes practices for automating software delivery and bringing development, operations and security activities together.

Service overview

The listed practices cover the path from code changes to deployment: teams can automate builds and tests, manage infrastructure through code, and package applications in containers. Monitoring and logging provide information about application and infrastructure health.

Release coordination, version control, code review and security checks are also part of the described scope. The official page names specific tools for several of these activities; the appropriate combination depends on the delivery environment.

Capabilities

Continuous integration and delivery

Set up CI/CD pipelines to automate builds, testing and deployments to staging or production environments. Regularly merging and testing changes helps reduce integration issues.

Automated testing

Automate unit, integration and end-to-end tests to identify software issues during delivery.

Infrastructure as code

Define and manage infrastructure using code and version control. The official page names Terraform and Ansible for automating cloud resource provisioning and configuration.

Containers and orchestration

Use Docker to create portable application environments and Kubernetes to deploy, scale and manage containers.

Monitoring and logging

Monitor application and infrastructure health and performance. Prometheus and the ELK stack are listed for collecting and analyzing logs and metrics.

Version control and code management

Use Git to manage code repositories and support code review and collaboration practices.

Release management

Plan releases with versioning and release notes, and prepare rollback strategies for deployment issues.

Security and compliance

Integrate security into development, review code and data handling, and perform compliance checks and vulnerability assessments.

Team collaboration

Coordinate development, operations and stakeholder communication. Slack and Microsoft Teams are listed as collaboration tools.

DevOps training and workshops

Provide training and workshops to help teams adopt DevOps practices and tools.
